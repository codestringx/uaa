================================================================================
                            QUICK START GUIDE
================================================================================

FOR LINUX/MAC/GIT BASH USERS:
-----------------------------
1. ./generate-uaa-keys.sh
2. ./gradlew clean :cloudfoundry-identity-uaa:assemble --no-daemon
3. docker compose up --build
4. curl http://localhost:8080/healthz

FOR WINDOWS CMD USERS:
----------------------
1. generate-uaa-keys.bat
2. Manually update config\uaa.yml with generated keys (see script output)
3. gradlew clean :cloudfoundry-identity-uaa:assemble --no-daemon
4. docker compose up --build
5. curl http://localhost:8080/healthz

  - jwt_pub.pem            (JWT public key)

================================================================================
                         WHY THESE KEYS ARE NEEDED
================================================================================

SAML Keys:
----------
UAA requires SAML Service Provider keys even if you're not using SAML
authentication. This is because SAML components are deeply integrated
into UAA's architecture and the application creates internal SAML
metadata during bootstrap.

JWT Keys:
---------
Used for signing and verifying OAuth2 access tokens and ID tokens.
The private key signs tokens, the public key verifies them.

================================================================================
                           TROUBLESHOOTING
================================================================================

Issue: "Metadata response is missing verification certificates"
Fix: Run ./generate-uaa-keys.sh and rebuild Docker

Issue: "corrupted stream - out of bounds length found"
Fix: JWT key is invalid - regenerate with ./generate-uaa-keys.sh

Issue: Database connection refused
Fix: Ensure PostgreSQL is running and database 'uaa' exists

Issue: Config changes not applied
Fix: docker compose build --no-cache && docker compose up -d

For more help, see: README-UAA-SETUP.md
